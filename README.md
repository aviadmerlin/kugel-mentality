# Kugel Mentality

Hebrew-language landing page for Idan Kugel, a mental performance coach for athletes. Introduces his coaching approach and programs for individuals, parents, and teams/clubs, with a WhatsApp contact CTA.

Designed, built, and deployed by me, end to end.

Live site: https://kugelmentality.com

## Tech
Static single-page site — vanilla HTML, CSS, and JavaScript (no framework/build step). RTL layout, scroll-triggered animations, photo/video gallery.
